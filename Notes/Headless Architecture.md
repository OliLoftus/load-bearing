# Headless Architecture

Separating the core engine/logic from the presentation/display layer, so
the engine works whether or not a UI is actually present.

Shows up as headless browsers (the rendering engine runs in full, only the
window/display step is skipped), headless CMS (content/logic exposed via
API, with the presentation layer built separately or swapped out entirely),
headless commerce (same split for storefronts).
